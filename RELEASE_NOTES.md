# Complete Korean FGA edition — first public release

This release contains the complete independent Korean edition of Alexandre Grothendieck’s eight FGA exposés, their errata and supplements, and the 1962 commentary in canonical order.

The primary artifact is the 140-page cumulative reader. It contains all 17 canonical components and preserves 209 historical source-page markers. Editable XeLaTeX sources, a public source-coverage manifest, sanitized evidence ledgers, the expert-review record, and exact SHA-256 manifests accompany it.

The reader was produced in one four-pass convergence build and then received one whole-reader aggregate inspection. There were no per-section or per-small-unit inspection loops and no repeated whole-reader run. This edition is maintained rigorously, but it does not claim perfection, infallibility, critical-edition status, external certification, or endorsement. Confirmed defects will be corrected in later immutable versions in the same lineage.
